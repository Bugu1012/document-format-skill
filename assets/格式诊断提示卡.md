# 格式诊断提示卡

提交 .docx 文档进行格式审查前，请确认以下信息，以便技能更准确地诊断和修订。

## 基本信息

- 文种：〔通知 / 报告 / 请示 / 函 / 决定 / 批复 / 意见 / 通报 / 公告 / 通告 / 议案 / 命令 / 决议 / 公报 / 纪要〕
- 发文机关：〔名称〕
- 是否联合行文：〔是 / 否〕

## 机关制度

- 本机关是否有自己的公文格式制度：〔是 / 否 / 不确定〕
- 如有，与 GB/T 9704-2012 的主要差异：〔行距 / 字体 / 页码位置 / 其他 ____〕

## 文档状态

- 文档来源：〔新建 / 从模板创建 / 从 PDF 转换 / 从旧文档修改〕
- 是否含涉密内容：〔是 / 否〕
- 是否含图片（发文机关标志、印章等）：〔是 / 否〕
- 是否含表格：〔是 / 否〕
- 是否含批注或修订标记：〔是 / 否〕

## 修订范围

- 修订范围：〔全文 / 仅版头 / 仅主体 / 仅版记 / 仅页面设置〕
- 是否需要保留原有批注和修订标记：〔是 / 否〕
- 输出方式：〔覆盖原文件 / 另存为新文件 / 仅出报告不修订〕

## 自检提示

在提交前，可以快速检查：

1. 用 Word 打开文档，查看"页面布局"→"页边距"是否为 37/35/28/26mm。
2. 选中正文段落，查看字体是否为"仿宋_GB2312"、字号是否为"三号"。
3. 查看段落行距是否为"固定值 28.95 磅"。
4. 查看标题字体是否为"方正小标宋体"。

如果以上任一项不符，技能大概率会检出偏差。
