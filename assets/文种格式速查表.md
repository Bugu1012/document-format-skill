# 文种格式速查表

15 种法定文种的格式差异速查。共同格式（正文字体字号、行距、页边距等）见 `references/字体字号规则.md` 和 `references/版面参数.md`，本表只列差异项。

## 标题格式

| 文种 | 标题构成 | 示例 |
|---|---|---|
| 决议 | 关于……的决议 | 关于×××的决议 |
| 决定 | 关于……的决定 | 关于×××的决定 |
| 命令（令） | 发文机关+令号 | ×××部令第×号 |
| 公报 | 会议名称+公报 | 中国共产党第×届中央委员会第×次全体会议公报 |
| 公告 | 关于……的公告 / 发文机关+公告 | 关于×××的公告 |
| 通告 | 关于……的通告 | 关于×××的通告 |
| 意见 | 关于……的意见 | 关于×××的意见 |
| 通知 | 关于……的通知 | 关于×××的通知 |
| 通报 | 关于……的通报 | 关于×××的通报 |
| 报告 | 关于……的报告 | 关于×××的报告 |
| 请示 | 关于……的请示 | 关于×××的请示 |
| 批复 | 关于……的批复 | 关于×××的批复 |
| 议案 | 关于……的议案 | 关于×××的议案 |
| 函 | 关于……的函 | 关于×××的函 |
| 纪要 | 会议名称+纪要（不套"关于"） | 第×次常务会议纪要 |

所有标题字体均为方正小标宋体、二号、居中。

## 主送机关

| 文种 | 主送机关 | 说明 |
|---|---|---|
| 决议、决定、命令、公报、公告、通告 | 通常无 | 面向公众或全体 |
| 意见、通知、通报 | 有 | 可多个 |
| 报告、请示 | 有（一个） | 请示只写一个主送机关 |
| 批复 | 有（一个） | 针对请示机关 |
| 议案 | 有 | 同级人大或常委会 |
| 函 | 有 | 不相隶属机关 |
| 纪要 | 按本机关制度 | 可有可无 |

## 版头特殊要素

| 文种 | 特殊要素 |
|---|---|
| 命令（令） | 签发人必备，标注令号 |
| 议案 | 含案由、方案 |
| 纪要 | 可标注期号"第×期" |
| 其他 | 按通用格式 |

## 行文方向

| 方向 | 文种 |
|---|---|
| 下行文 | 决议、决定、命令、公报、公告、通告、意见、通知、通报、批复 |
| 上行文 | 报告、请示、议案 |
| 平行文 | 函 |
| 多向 | 纪要（按印发范围） |

## 常见混淆

| 混淆 | 区分要点 |
|---|---|
| 通知 vs 通报 | 通知侧重部署执行、转发文件；通报侧重表彰批评、传达情况 |
| 报告 vs 请示 | 报告不含请示事项；请示一文一事、只写一个主送机关 |
| 决定 vs 决议 | 决定可由机关直接作出；决议须经会议通过 |
| 公告 vs 通告 | 公告面向国内外；通告面向一定范围 |
| 意见 vs 通知 | 意见侧重见解和主张；通知侧重执行和办理 |
