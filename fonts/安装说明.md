# 公文字体安装说明

本目录包含公文格式修订所需的三个字体文件。黑体（SimHei）为 Windows 系统自带，无需安装。

## 字体清单

| 文件名 | 字体名 | 用途 | 大小 |
|---|---|---|---|
| 仿宋_GB2312.ttf | 仿宋_GB2312 | 正文、三级/四级标题、附件、落款 | 3.8 MB |
| 方正小标宋.TTF | 方正小标宋简体 | 公文标题 | 3.6 MB |
| 楷体_GB2312.ttf | 楷体_GB2312 | 二级标题「（一）」 | 3.9 MB |

## 自动安装（推荐）

```bash
python fonts/install_fonts.py
```

脚本会将字体安装到当前用户字体目录（`%LOCALAPPDATA%\Microsoft\Windows\Fonts`），无需管理员权限。
已安装的字体自动跳过。安装后部分应用需重启才能识别新字体。

## 手动安装

右键点击字体文件 → 「安装」（Windows 10 1809+ 默认安装到用户目录）。
或复制字体文件到 `C:\Windows\Fonts`（需管理员权限）。

## WPS 用户

WPS Office 自带仿宋_GB2312、方正小标宋简体、楷体_GB2312，无需额外安装。

## 版权提示

- 方正小标宋简体为北京北大方正电子有限公司商业字体。本仓库随附该字体仅供内部使用，
  不得用于商业再分发。如需公开仓库，请在 `.gitignore` 中取消 `fonts/` 的注释以排除字体文件。
- 仿宋_GB2312、楷体_GB2312 为早期 Windows 系统附带字体，版权边界较模糊，
  建议同样在公开仓库中排除。
- 获取正版字体的正规渠道：方正字库官网（https://www.foundertype.com）。
