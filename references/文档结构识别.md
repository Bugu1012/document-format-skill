# 文档结构识别

本文件规定如何从 .docx 公文中识别版头、主体、版记各要素。核验日期为二〇二六年七月二十九日。

## 三段式结构

公文由版头、主体、版记三部分组成：

```
版头：份号、密级和保密期限、紧急程度、发文机关标志、发文字号、签发人
主体：标题、主送机关、正文、附件说明、发文机关署名、成文日期、印章、附注、附件
版记：抄送机关、印发机关和印发日期
```

## 要素识别策略

| 识别目标 | 位置特征 | 文本特征 | 格式特征 | 置信度判断 |
|---|---|---|---|---|
| 发文机关标志 | 文档最前 | 含机关全称或规范简称 | 红色、小标宋体、居中 | 高：红色+居中+大字号 |
| 发文字号 | 标志下方 | 匹配 `X〔20XX〕X号` 或 `X[20XX]X号` | 仿宋、三号 | 高：正则命中 |
| 签发人 | 发文字号右侧或下方 | 含"签发人"三字 | 楷体 | 中：需结合位置 |
| 标题 | 前 5 段内 | 匹配"关于……的通知/决定/报告/请示/函"等 | 方正小标宋体、二号、居中 | 高：格式+模式双命中 |
| 主送机关 | 标题后第一段 | 以"："结尾，或含"各省/各市/各厅/各部" | 仿宋、三号、左对齐 | 中：需结合位置 |
| 正文 | 主送机关后 | 无特殊标记 | 仿宋_GB2312、三号、首行缩进 | 高：格式命中 |
| 一级标题 | 正文内 | 匹配 `一、` `二、` … `十、` 开头 | 黑体、三号 | 高：正则+格式 |
| 二级标题 | 正文内 | 匹配 `（一）` `（二）` … 开头 | 楷体_GB2312、三号 | 高：正则+格式 |
| 三级标题 | 正文内 | 匹配 `1.` `2.` … 开头 | 仿宋_GB2312、三号、加粗 | 中：正则命中但易与编号混淆 |
| 附件说明 | 正文后 | 匹配"附件："或"附件：1." | 仿宋、三号 | 高：正则命中 |
| 发文机关署名 | 附件说明后或正文后 | 机关名称 | 仿宋、三号、右对齐 | 中：需结合位置 |
| 成文日期 | 署名下方 | 匹配 `20XX年X月X日` | 仿宋、三号、右对齐 | 高：正则+位置 |
| 附注 | 成文日期下方 | 圆括号括入 | 仿宋、三号 | 中：需结合格式 |
| 抄送机关 | 文档末尾区域 | 匹配"抄送：" | 仿宋、四号 | 高：正则命中 |
| 印发机关和印发日期 | 文档最末 | 匹配"印发"或含日期 | 仿宋、四号 | 高：正则+位置 |

## 识别优先级

当多个规则冲突时，按以下优先级判断：

1. 格式特征（字体、字号、对齐）优先于位置特征。
2. 文本模式（正则匹配）优先于位置推断。
3. 位置特征作为辅助确认。
4. 无法确定时标注 `〔待确认〕`，不猜测。

## 15 种文种的结构特征差异

| 文种 | 标题特征 | 主送机关 | 特殊要素 |
|---|---|---|---|
| 决议 | "关于……的决议" | 通常无 | 经会议通过 |
| 决定 | "关于……的决定" | 可有可无 | |
| 命令（令） | 含发文机关+令号 | 通常无 | 签发人必备 |
| 公报 | 会议名称+公报 | 通常无 | |
| 公告 | "关于……的公告" | 通常无 | 面向公众 |
| 通告 | "关于……的通告" | 通常无 | 面向公众 |
| 意见 | "关于……的意见" | 有 | |
| 通知 | "关于……的通知" | 有 | 最常见文种 |
| 通报 | "关于……的通报" | 有 | |
| 报告 | "关于……的报告" | 有 | 不含请示事项 |
| 请示 | "关于……的请示" | 有（一个） | 一文一事 |
| 批复 | "关于……的批复" | 有（一个） | 针对请示 |
| 议案 | "关于……的议案" | 有 | 含案由 |
| 函 | "关于……的函" | 有 | 不相隶属机关 |
| 纪要 | "会议名称+纪要" | 按制度 | 不套"关于"格式 |

## 联合行文

- 发文机关标志可并用联合发文机关名称，也可单独用主办机关名称。
- 发文字号使用主办机关的。
- 标题中可列出联合发文机关。

## 有附件时

- 附件说明在正文之后、发文机关署名之前。
- 格式："附件：1. 附件名称"。
- 附件本身另起一页，附件标题格式按本机关制度。

## 识别置信度评估

| 置信度 | 条件 | 处理 |
|---|---|---|
| 高 | 格式+文本模式双命中 | 直接采用 |
| 中 | 仅单一特征命中 | 采用但标注 |
| 低 | 仅位置推断或特征冲突 | 标注 `〔待确认〕`，触发 grill-me |

## 非标准文档处理

以下情况识别率会下降：

- 从 PDF 转换而来的 .docx：格式信息可能丢失或错乱。
- 格式严重混乱的文档：可能无法可靠识别要素。
- 含大量表格的文档：表格内文字不参与段落级识别。
- 使用非标准字体的文档：字体特征失效，依赖文本模式和位置。

处理原则：识别置信度低时，不强行修订，先向用户确认文档结构。
