# 修订报告规范

本文件规定修订报告的字段定义、严重度分级和规则引用格式。核验日期为二〇二六年七月二十九日。

## 报告字段

| 字段 | 必填 | 说明 |
|---|---|---|
| 文件名 | 是 | 被审查的 .docx 文件名 |
| 文种判断 | 是 | 识别出的文种及置信度（高/中/低） |
| 段落数 | 是 | 文档总段落数 |
| 审查日期 | 是 | YYYY-MM-DD |
| 适用规则 | 是 | GB/T 9704-2012 基线 / 本机关制度 |
| 修订统计 | 是 | 严重/一般/提示各多少项 |
| 修订明细 | 是 | 逐项列出 |
| 待确认项 | 否 | 需用户确认的事项 |
| 超出能力项 | 否 | 超出技能范围的事项 |
| 处理说明 | 是 | 审查范围和方法说明 |

## 修订明细字段

每条修订明细包含：

| 字段 | 说明 |
|---|---|
| 位置 | `段落 N（要素类型）` 或 `页面设置` 或 `页脚` |
| 要素 | 具体格式属性（如"正文字体""行距""上边距"） |
| 当前值 | 文档中的实际值 |
| 标准值 | 应修正为的值 |
| 依据 | 规则条款（如 `GB/T 9704-2012 §7.3.3`） |
| 严重度 | 严重 / 一般 / 提示 |

## 严重度分级标准

| 级别 | 标准 | 示例 |
|---|---|---|
| 严重 | 影响整体版面合规性 | 页边距错误、正文字体字号错误、行距错误、纸张错误 |
| 一般 | 影响局部要素合规性 | 标题字体偏差、个别要素字号偏差、发文字号括号错误 |
| 提示 | 不影响合规判定但建议修正 | 层次序数不规范、页码格式微调、段前段后间距不一致 |

## 规则引用格式

- 国标条款：`GB/T 9704-2012 §X.X.X`
- 条例条款：《党政机关公文处理工作条例》第X条
- 本机关制度：`本机关制度（名称）第X条`

## 位置标注格式

- 段落级：`段落 N（要素类型）`，N 从 1 开始。
- 页面级：`页面设置` 或 `节 N 页面设置`（多节文档）。
- 页脚级：`页脚` 或 `节 N 页脚`。
- 表格内：`表格 N 第 R 行第 C 列`。

## 未验证项标注

对于无法确认的事项：

- `〔待确认：事项〕`：需用户确认机关制度或文种选择。
- `〔超出能力：事项〕`：图片操作、OCR 等超出范围。
- 不将"待确认"项计入修订统计。

## 报告输出原则

- 先列严重，再列一般，最后列提示。
- 同类错误合并（如"段落 3-47 正文字体均为宋体"）。
- 不输出无偏差的要素（避免冗长）。
- 处理说明中明确"未修改任何文字内容"。
