# 字体字号规则

本文件提供公文各要素的字体字号规则。以 GB/T 9704-2012 为基线，以本机关现行制度为准。核验日期为二〇二六年七月二十九日。

## 易混淆字体

| 正确字体 | 常见误用 | 区别 |
|---|---|---|
| 仿宋_GB2312 | 仿宋 | 仿宋_GB2312 是 GB2312 字符集版本，字形略有差异；公文正文应使用仿宋_GB2312 |
| 楷体_GB2312 | 楷体 | 同上，公文二级标题和签发人应使用楷体_GB2312 |
| 方正小标宋体 | 华文中宋、宋体加粗 | 方正小标宋体是专用标题字体，不可用其他字体替代 |
| 黑体 | 微软雅黑、思源黑体 | 公文一级标题应使用黑体（SimHei），不使用无衬线黑体 |

## 字体回退链

当目标字体不可用时：

| 目标字体 | 回退方案 | 说明 |
|---|---|---|
| 方正小标宋体 | 华文中宋 → 宋体加粗 | 仅用于显示预览；正式文件必须安装方正小标宋体 |
| 仿宋_GB2312 | 仿宋 → STFangsong（macOS） | python-docx 写入字体名即可，渲染取决于系统 |
| 楷体_GB2312 | 楷体 → STKaiti（macOS） | 同上 |
| 黑体 | SimHei → STHeiti（macOS） | 同上 |

注意：python-docx 只写入字体名称到 .docx XML，不嵌入字体文件。实际渲染取决于打开文档的系统是否安装了对应字体。

## 条件变体

- 联合行文：发文机关标志可用文件头形式，字体仍为小标宋体（红色）。
- 命令（令）：标题含发文机关名称和令号，字体仍为方正小标宋体。
- 会议纪要：标题通常采用"会议名称+纪要"合成式，字体仍为方正小标宋体。

## python-docx 字体设置要点

公文中数字和拉丁字母应使用与中文相同的字体。设置时统一 ascii、hAnsi、eastAsia 三个属性：

```python
run.font.name = '仿宋_GB2312'
rfonts = run._element.get_or_add_rPr().get_or_add_rFonts()
rfonts.set(qn('w:eastAsia'), '仿宋_GB2312')
rfonts.set(qn('w:ascii'), '仿宋_GB2312')
rfonts.set(qn('w:hAnsi'), '仿宋_GB2312')
```

不要将 ascii/hAnsi 设为 Times New Roman，否则文档中的数字（如"2026年""12345"）和拉丁字母（如"OA""12345"）会使用 Times New Roman 而非公文标准字体。详见 `python-docx操作手册.md`。
