# 结构层次序数

本文件规定公文正文的结构层次序数规则。核验日期为二〇二六年七月二十九日。

## 四级层次

```
一、第一层次（黑体，三号）
  （一）第二层次（楷体_GB2312，三号）
    1. 第三层次（仿宋_GB2312，三号，加粗）
      （1）第四层次（仿宋_GB2312，三号，不加粗）
```

## 规则

1. 严格按顺序使用，不跳级。不得从"一、"直接跳到"1."。
2. 每一层次至少有两个同级项（不能只有一个"一、"而没有"二、"）。
3. 同一层次内序数连续，不跳号。
4. 第三层次"1."后使用下脚点（.），不使用顿号（、）。
5. 第四层次"（1）"后不加任何标点。
6. 第一层次"一、"后使用顿号。
7. 第二层次"（一）"后不加任何标点。

## 常见错误

| 错误 | 正确 | 说明 |
|---|---|---|
| `1、` | `1.` | 第三层次用下脚点，不用顿号 |
| `（1）、` | `（1）` | 第四层次后不加标点 |
| `(一)` | `（一）` | 使用中文全角括号 |
| `一.` | `一、` | 第一层次用顿号 |
| 从"一、"直接到"1." | 从"一、"到"（一）"再到"1." | 不跳级 |
| 只有一个"一、" | 至少两个同级项，或不用序数 | 单项不编号 |
| `1、` 和 `（一）` 混用 | 统一使用规定层次 | 不混用 |

## 标题与正文的区分

- 层次标题独占一行时，按标题字体处理（黑体/楷体/加粗仿宋）。
- 层次标题与正文接排（标题后紧跟正文）时，标题部分仍用标题字体，正文部分用正文字体。
