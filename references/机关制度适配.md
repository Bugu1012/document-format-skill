# 机关制度适配

本文件说明如何处理各机关自有版式制度与 GB/T 9704-2012 基线的关系。核验日期为二〇二六年七月二十九日。

## 为什么需要适配

GB/T 9704-2012 是推荐性国家标准。各机关可以依据《党政机关公文处理工作条例》和上级机关规定，制定自己的公文格式细则。常见差异：

| 差异项 | GB/T 9704-2012 基线 | 常见机关变体 |
|---|---|---|
| 行距 | 固定值 28.95pt | 部分机关使用 28pt 或 29pt |
| 正文字体 | 仿宋_GB2312 | 部分机关接受仿宋（非 GB2312 版） |
| 标题字体 | 方正小标宋体 | 部分机关使用华文中宋 |
| 页码位置 | 版心下边缘之下 | 部分机关放在页脚居中 |
| 版头红线 | 标准未规定具体线宽 | 各机关有自己的红线规格 |
| 成文日期位置 | 正文后右空四字 | 部分机关有不同位置要求 |
| 主送机关格式 | 左空一字 | 部分机关顶格 |

## 适配流程

1. 默认以 GB/T 9704-2012 为基线执行诊断。
2. 如果用户明确说明本机关有自己的版式制度：
   a. 询问具体差异项（使用 grill-me 结构化多选）。
   b. 将用户确认的差异项记录到决策日志。
   c. 修订时用用户确认的值覆盖默认基线。
3. 如果用户不确定是否有自己的制度：
   a. 按基线执行。
   b. 在修订报告中标注"按 GB/T 9704-2012 基线修订，如本机关有自己制度请确认"。
4. 如果基线与机关制度冲突：
   a. 提示用户确认适用哪一套。
   b. 不自行判断优先级。

## 决策日志格式

```
〔机关制度确认〕
- 适用规则：GB/T 9704-2012 基线 / 本机关制度（名称：____）
- 行距：28.95pt / 自定义 ____pt
- 正文字体：仿宋_GB2312 / 自定义 ____
- 标题字体：方正小标宋体 / 自定义 ____
- 其他差异：____
- 确认时间：YYYY-MM-DD
```

## 注意事项

- 不要把某一家机关的制度当作通用规则。
- 不要假设所有机关都有自己制度（多数机关直接执行国标）。
- 用户未提及时，不主动追问机关制度（避免不必要的交互）。
- 用户提及后，只问差异项，不要求用户提供制度全文。
