# 资料导航

本技能的资料采用"主文件简洁、参考文件分层"的方式组织。处理简单咨询时，可以只读主技能文件；处理完整审查和修订时，按本导航加载对应资料。

## 使用顺序

1. 先读 `规范依据.md`，确认当前任务涉及的标准和制度边界。
2. 格式咨询：读对应规则文件（`字体字号规则.md`、`版面参数.md`、`结构层次序数.md`、`页码与页眉页脚.md`）。
3. 格式审查：读 `文档结构识别.md` + `常见格式错误图谱.md`，配合 `assets/格式审查清单.md`。
4. 格式修订：读 `python-docx操作手册.md` + `字体与环境依赖.md`，配合 `assets/python-docx修订代码模板.md`。
5. 涉及机关制度差异：读 `机关制度适配.md`。
6. 需要文种格式差异：读 `assets/文种格式速查表.md`。
7. 批量处理：读 `assets/批量处理配置模板.md`。
8. 维护或迭代本技能时，可读 `开源技能参考借鉴.md`，但不要把它当作格式规范依据。

## 加载原则

- 简单咨询（如"正文字体应该是什么"）：只读 SKILL.md + 对应规则文件。
- 完整审查：读结构识别 + 错误图谱 + 审查清单 + 对应规则文件。
- 执行修订：加读 python-docx 手册 + 代码模板。
- 不要把全部 references 一次性加载（总量约 40KB，消耗上下文）。
