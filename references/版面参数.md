# 版面参数

本文件提供公文版面参数的精确值。以 GB/T 9704-2012 为基线。核验日期为二〇二六年七月二十九日。

## 纸张与页边距

| 参数 | 标准值 | 容差 | python-docx 设置 |
|---|---|---|---|
| 纸张 | A4（210mm × 297mm） | — | `section.page_width = Mm(210)` / `section.page_height = Mm(297)` |
| 上边距（天头） | 37mm | ±1mm | `section.top_margin = Mm(37)` |
| 下边距（地脚） | 35mm | ±1mm | `section.bottom_margin = Mm(35)` |
| 左边距（订口） | 28mm | ±1mm | `section.left_margin = Mm(28)` |
| 右边距（切口） | 26mm | ±1mm | `section.right_margin = Mm(26)` |

## 版心

| 参数 | 值 | 计算 |
|---|---|---|
| 版心宽度 | 156mm | 210 - 28 - 26 = 156 |
| 版心高度 | 225mm | 297 - 37 - 35 = 225 |

## 行距与排版

| 参数 | 标准值 | 说明 |
|---|---|---|
| 正文行距 | 固定值 28.95pt（579 twips） | 每面排 22 行 |
| 每行字数 | 28 字 | 三号字（16pt）× 28 ≈ 156mm 版心宽度 |
| 每面行数 | 22 行 | 28.95pt × 22 ≈ 225mm 版心高度 |
| 首行缩进 | 2 字符 | 正文段落 |
| 装订 | 左侧装订 | |

python-docx 行距设置：

```python
from docx.shared import Pt
paragraph_format.line_spacing = Pt(28.95)
paragraph_format.line_spacing_rule = WD_LINE_SPACING.EXACTLY
```

python-docx 首行缩进设置：

```python
from docx.shared import Pt
paragraph_format.first_line_indent = Pt(32)  # 2 字符 × 16pt = 32pt
```

## 标题排版

| 参数 | 要求 |
|---|---|
| 位置 | 居中 |
| 回行 | 保持词意完整，不将词组拆成两行 |
| 行距 | 与正文相同（固定值 28.95pt） |
| 段前段后 | 标准未明确规定，按本机关制度处理 |

## 段前段后间距（可配置）

GB/T 9704-2012 未明确规定各要素的段前段后间距。默认修订策略为全部设为 0。
部分机关（尤其国企）有内部制度要求标题段前留白，常见实践如下：

| 要素 | 常见段前 | 常见段后 | 说明 |
|---|---|---|---|
| 大标题 | 0 | 1.5 行（43.425pt） | 标题与正文之间留白 |
| 一级标题「一、」 | 1 行（28.95pt） | 0 | 与上文拉开层次 |
| 二级标题「（一）」 | 0.5 行（14.475pt） | 0 | 轻度层次区分 |
| 正文 / 三级 / 四级 | 0 | 0 | 无额外间距 |

启用条件：用户明确要求或本机关制度有规定时，使用 ssets/python-docx修订代码模板.md 中的
ix_heading1_with_spacing、ix_heading2_with_spacing、ix_title_with_spacing 函数。
未确认机关制度前，保持默认全 0，不主动添加段前段后间距。

## 双面打印与单面打印

| 打印方式 | 页码位置 | 页边距 |
|---|---|---|
| 单面打印 | 居中 | 左右页边距相同 |
| 双面打印 | 单页码居右空 1 字，双页码居左空 1 字 | 可设镜像页边距 |

## 版头分隔线

版头与主体之间有一条红色分隔线（俗称"红线"）。线宽和位置按本机关制度处理。python-docx 对段落边框的控制有限，可能需要 XML 直接操作。

## 常见页面设置错误

| 错误 | 常见原因 | 修正 |
|---|---|---|
| 页边距为 Word 默认值（25.4/31.8mm） | 新建文档未设置 | 按标准值设置四边 |
| 行距为"单倍行距"或"1.5倍行距" | 未设固定值 | 改为固定值 28.95pt |
| 纸张为 Letter（216×279mm） | Word 默认纸张 | 改为 A4 |
| 每页行数不是 22 行 | 行距或字号不对 | 检查行距和字号组合 |
