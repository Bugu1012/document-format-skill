## 字体安装

### Windows

- 黑体、宋体：系统自带，无需安装。
- 仿宋_GB2312、楷体_GB2312：Windows 7 及之前自带；Windows 10/11 可能只有"仿宋"和"楷体"（非 GB2312 版本），需手动安装 GB2312 版本。
- 方正小标宋体：需从方正官网下载或从机关字体包获取。
- 安装方法：右键字体文件 → "为所有用户安装"。

### macOS

- 系统无仿宋_GB2312、楷体_GB2312、黑体（SimHei）。
- 有 STSong、STFangsong、STKaiti、STHeiti 等华文系列字体，字形与 GB2312 版本有差异。
- 需手动安装 Windows 字体文件到"字体册"。

### Linux

- 默认无中文字体。
- 安装 `fonts-wqy-microhei` 等开源字体可作为显示替代。
- 正式排版需安装方正字体和 GB2312 字体。

## python-docx 与字体的关系

python-docx 只将字体名称写入 .docx 的 XML 中（`w:rFonts` 元素），不嵌入字体文件。

这意味着：

- 生成 .docx 的机器不需要安装目标字体。
- 打开 .docx 的机器如果未安装目标字体，会回退到系统默认字体显示。
- 打印时如果字体不可用，输出可能与预期不同。

## 跨平台渲染差异

| 场景 | Windows + Office | macOS + Office | WPS |
|---|---|---|---|
| 仿宋_GB2312 | 正常（如已安装） | 可能回退为 STFangsong | 通常自带 |
| 方正小标宋体 | 正常（如已安装） | 可能回退为宋体 | 需安装 |
| 行距 28.95pt | 精确 | 精确 | 可能有微小差异 |
| 页码域代码 | 正常更新 | 正常更新 | 正常更新 |

## 修订时的字体处理策略

1. 修订代码中写入标准字体名称（如"仿宋_GB2312"），不管当前系统是否安装。
2. 在修订报告中标注字体依赖：提示用户确认目标字体已安装。
3. 如果用户确认字体不可用，在 `〔待确认〕` 中记录，不强行替换为非标准字体。
4. 字体回退只用于预览参考，不写入正式修订文件。

## 检测系统字体（可选）

```python
import subprocess
import platform

def check_font_installed(font_name):
    """检查系统是否安装了指定字体（仅 Windows）"""
    if platform.system() != 'Windows':
        return None  # 非 Windows 不检测
    try:
        result = subprocess.run(
            ['powershell', '-Command',
             f"[System.Drawing.Text.InstalledFontCollection]::new().Families | Where-Object {{ $_.Name -eq '{font_name}' }}"],
            capture_output=True, text=True, timeout=10
        )
        return font_name in result.stdout
    except Exception:
        return None
```

此检测为可选辅助，不影响修订逻辑。

## .doc 格式处理

python-docx 只能打开 .docx（OOXML 格式），不能直接打开 .doc（OLE2 二进制格式）。

遇到 .doc 文件时的处理策略：

1. 提示用户先在 Word 或 WPS 中「另存为」.docx，再提交修订。
2. Windows 环境下可用 Word COM 自动化转换（需安装 Microsoft Word）：

```python
import win32com.client

def convert_doc_to_docx(doc_path, docx_path):
    word = win32com.client.Dispatch("Word.Application")
    word.Visible = False
    doc = word.Documents.Open(os.path.abspath(doc_path))
    doc.SaveAs2(os.path.abspath(docx_path), FileFormat=16)  # 16 = wdFormatXMLDocument
    doc.Close()
    word.Quit()
```

3. macOS 环境下可用系统自带 textutil：`textutil -convert docx input.doc -output output.docx`。
4. 无 Word 环境时，不支持自动转换，须用户手动处理。

注意：.doc 转 .docx 后格式可能有细微偏差（尤其旧版 Word 97-2003），转换后应重新执行格式诊断。
