# 页码与页眉页脚

本文件规定公文页码格式和页眉页脚处理。核验日期为二〇二六年七月二十九日。

## 页码格式

| 参数 | 标准值 |
|---|---|
| 字体 | 半角宋体 |
| 字号 | 四号（14pt） |
| 数字 | 阿拉伯数字 |
| 格式 | — X —（两侧各一个一字线，一字线与数字之间各空一个半角空格） |
| 位置（单面打印） | 版心下边缘之下，居中 |
| 位置（双面打印） | 单页码居右空 1 字，双页码居左空 1 字 |

## 页码起始

- 公文一般从正文第一页开始编页码。
- 版头部分（发文机关标志、发文字号等）不编页码。
- 如果版头占一页以上，从正文所在页开始编"1"。

## python-docx 页码实现

python-docx 没有原生页码域代码支持，需要通过 XML 直接操作：

```python
from docx.oxml.ns import qn
from docx.oxml import OxmlElement

def add_page_number(paragraph):
    """在段落中插入 — X — 格式的页码域"""
    # 前一字线
    run1 = paragraph.add_run('— ')
    run1.font.name = '宋体'
    run1.font.size = Pt(14)

    # 页码域代码
    fldChar1 = OxmlElement('w:fldChar')
    fldChar1.set(qn('w:fldCharType'), 'begin')
    instrText = OxmlElement('w:instrText')
    instrText.set(qn('xml:space'), 'preserve')
    instrText.text = ' PAGE '
    fldChar2 = OxmlElement('w:fldChar')
    fldChar2.set(qn('w:fldCharType'), 'end')

    run2 = paragraph.add_run()
    run2.font.name = '宋体'
    run2.font.size = Pt(14)
    run2._element.append(fldChar1)
    run2._element.append(instrText)
    run2._element.append(fldChar2)

    # 后一字线
    run3 = paragraph.add_run(' —')
    run3.font.name = '宋体'
    run3.font.size = Pt(14)
```

## 页眉页脚

| 要素 | 规则 |
|---|---|
| 页眉 | 公文一般不设页眉。按本机关制度处理。 |
| 页脚 | 放置页码。 |
| 版头红线 | 版头与主体之间的红色分隔线，不是页眉，是正文第一页的段落边框或图片。 |

## 首页不同

如果版头（发文机关标志等）在首页，正文从第二页开始：

- 设置节（section）的"首页不同"属性。
- 首页页脚留空。
- 后续页页脚放页码。

```python
section.different_first_page_header_footer = True
```

## 双面打印设置

```python
section.different_odd_even = True
# 奇数页页码居右
# 偶数页页码居左
```

## 常见错误

| 错误 | 修正 |
|---|---|
| 页码无一字线，只有数字 | 添加 — X — 格式 |
| 页码字体为 Times New Roman | 改为半角宋体 |
| 页码字号为五号 | 改为四号（14pt） |
| 版头页也编了页码 | 设置首页不同，首页不编页码 |
| 页码在页面最底部 | 应在版心下边缘之下 |

## 浮动文本框页码的处理

部分文档的页码不在普通段落中，而是放在浮动文本框（`wp:anchor`）内，导致位置偏左或偏右。python-docx 无法直接操作浮动文本框内的内容。

处理方法：清除页脚中所有现有段落（含浮动对象），重建为居中段落 + PAGE 域代码。代码见 `assets/python-docx修订代码模板.md` "页脚重建"章节。

## python-docx 局限

- 页码域代码需要 XML 直接操作（见上方代码）。
- 浮动文本框中的页码需要清除后重建（见上方说明）。
- 页码位置（距版心下边缘的距离）需要精确计算页脚边距。
- 双面打印的奇偶页不同页码位置需要分别设置奇数页和偶数页页脚。
- 版头红线（段落边框）的精确控制可能需要直接操作 `w:pBdr` XML 元素。
