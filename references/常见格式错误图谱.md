# 常见格式错误图谱

本文件收录公文格式高频错误，按严重度和频率排列。核验日期为二〇二六年七月二十九日。

## 严重级错误

### S01 页边距为 Word 默认值

- 位置：页面设置
- 表现：上下 25.4mm，左右 31.8mm（或 25.4mm）
- 根因：新建文档未修改默认页边距
- 修正：上 37mm、下 35mm、左 28mm、右 26mm
- 依据：GB/T 9704-2012 §5.1
- 代码：`section.top_margin = Mm(37)` 等

### S02 纸张为 Letter

- 位置：页面设置
- 表现：216mm × 279mm
- 根因：Word 默认纸张为 Letter（北美标准）
- 修正：A4（210mm × 297mm）
- 依据：GB/T 9704-2012 §5.1
- 代码：`section.page_width = Mm(210); section.page_height = Mm(297)`

### S03 正文字体为宋体

- 位置：正文段落
- 表现：宋体（SimSun）而非仿宋_GB2312
- 根因：Word 默认中文字体为宋体
- 修正：仿宋_GB2312，三号
- 依据：GB/T 9704-2012 §7.3.3
- 代码：设置 `w:eastAsia` 属性为"仿宋_GB2312"

### S04 行距为单倍或 1.5 倍

- 位置：正文段落
- 表现：行距随字号变化，不是固定值
- 根因：Word 默认行距为"单倍行距"或"多倍行距 1.15"
- 修正：固定值 28.95pt（579 twips）
- 依据：GB/T 9704-2012 §5.2.2
- 代码：`pf.line_spacing = Pt(28.95); pf.line_spacing_rule = WD_LINE_SPACING.EXACTLY`

### S05 正文字号不是三号

- 位置：正文段落
- 表现：五号（10.5pt）或小四（12pt）
- 根因：Word 默认字号为五号
- 修正：三号（16pt）
- 依据：GB/T 9704-2012 §7.3.3
- 代码：`run.font.size = Pt(16)`

### S06 首行未缩进

- 位置：正文段落
- 表现：顶格排列
- 根因：未设置首行缩进
- 修正：首行缩进 2 字符（32pt）
- 依据：GB/T 9704-2012 §7.3.3
- 代码：`pf.first_line_indent = Pt(32)`

## 一般级错误

### M01 标题字体不是方正小标宋体

- 位置：标题段落
- 表现：宋体加粗、黑体或华文中宋
- 根因：未安装方正小标宋体或使用替代字体
- 修正：方正小标宋体，二号（22pt），居中
- 依据：GB/T 9704-2012 §7.3.1

### M02 一级标题字体不是黑体

- 位置：一级标题段落
- 表现：仿宋加粗或宋体加粗
- 根因：误用正文字体加粗代替黑体
- 修正：黑体（SimHei），三号，不加粗
- 依据：GB/T 9704-2012 §7.3.3

### M03 二级标题字体不是楷体

- 位置：二级标题段落
- 表现：仿宋或宋体
- 根因：未区分层次标题字体
- 修正：楷体_GB2312，三号，不加粗
- 依据：GB/T 9704-2012 §7.3.3

### M04 发文字号括号错误

- 位置：发文字号
- 表现：使用方括号 `[2026]` 或圆括号 `(2026)`
- 根因：输入法或习惯
- 修正：六角括号 `〔2026〕`
- 依据：GB/T 9704-2012 §7.2.5

### M05 成文日期格式错误

- 位置：成文日期
- 表现：使用"二〇二六年七月二十九日"（汉字数字）或"2026.7.29"
- 根因：旧标准使用汉字数字，2012 版改为阿拉伯数字
- 修正：阿拉伯数字全称"2026年7月29日"，不编虚位
- 依据：GB/T 9704-2012 §7.3.5.4

### M06 抄送机关字号错误

- 位置：版记
- 表现：三号字（与正文相同）
- 根因：未区分版记字号
- 修正：仿宋_GB2312，四号（14pt）
- 依据：GB/T 9704-2012 §7.4.1

### M07 标题未居中

- 位置：标题段落
- 表现：左对齐
- 根因：未设置对齐方式
- 修正：居中对齐
- 依据：GB/T 9704-2012 §7.3.1
- 代码：`pf.alignment = WD_ALIGN_PARAGRAPH.CENTER`


### S07 使用装饰性字体

- 位置：全文
- 表现：华文彩云、华文行楷、方正舒体等艺术字体
- 根因：用户误选装饰字体或从模板继承
- 修正：按要素分别设置标准字体（标题方正小标宋体、正文仿宋_GB2312、一级标题黑体、二级标题楷体_GB2312）
- 依据：GB/T 9704-2012 §7.3.1, §7.3.3
- 说明：此类错误通常全文一致，修订时需逐要素分别设置，不能全文统一替换为单一字体


### S08 文字颜色非黑色

- 位置：全文段落
- 表现：红色、蓝色、绿色等非黑色文字
- 根因：装饰性字体常伴随彩色；或从网页/模板复制带入
- 修正：统一为黑色（RGB 0,0,0）
- 依据：GB/T 9704-2012 §7.3.1（公文用字规范）
- 代码：un.font.color.rgb = RGBColor(0, 0, 0)
- 说明：常与 S07（装饰性字体）同时出现，修订字体后须检查颜色是否残留
### M08 二级标题接排正文未分字体

- 位置：二级标题段落
- 表现：标题和接排正文使用相同字体
- 根因：未区分标题 run 和正文 run
- 修正：标题部分（原始加粗 run）用楷体_GB2312，正文部分用仿宋_GB2312
- 依据：GB/T 9704-2012 §7.3.3
- 代码：按 run.font.bold 区分，见 `assets/python-docx修订代码模板.md`
## 提示级错误

### L01 结构层次跳级

- 位置：正文
- 表现：从"一、"直接到"1."，跳过"（一）"
- 根因：作者未注意层次规则
- 修正：补充中间层次或调整编号
- 依据：GB/T 9704-2012 §7.3.3

### L02 第三层次使用顿号

- 位置：正文
- 表现："1、"而非"1."
- 根因：中文输入习惯
- 修正：改为"1."（下脚点）
- 依据：GB/T 9704-2012 §7.3.3

### L03 页码格式不规范

- 位置：页脚
- 表现：只有数字"1"，无一字线
- 根因：未设置页码格式
- 修正：— 1 —（两侧各一字线）
- 依据：GB/T 9704-2012 §7.5

### L04 使用半角括号

- 位置：第二/四层次标题
- 表现："(一)"而非"（一）"
- 根因：输入法状态
- 修正：全角括号"（一）"
- 依据：GB/T 9704-2012 §7.3.3

### L05 段前段后间距不一致

- 位置：各段落
- 表现：部分段落有额外段前/段后间距
- 根因：Word 默认样式或手动调整
- 修正：统一为 0（标准未规定段前段后间距）
- 说明：按本机关制度处理


### L06 页码在浮动文本框中位置偏移

- 位置：页脚
- 表现：页码偏左或偏右，不居中
- 根因：页码放在浮动文本框（wp:anchor）中，文本框水平对齐为 left 或 right
- 修正：清除浮动文本框，重建为居中段落 + PAGE 域代码
- 依据：GB/T 9704-2012 §7.5（单面打印居中）
- 代码：见 `assets/python-docx修订代码模板.md` "页脚重建"章节
## 错误统计参考

根据实际审查经验，高频错误排序：

1. S03 正文字体为宋体（约 80% 的新建文档）
2. S04 行距不是固定值（约 75%）
3. S01 页边距为默认值（约 70%）
4. S06 首行未缩进（约 60%）
5. S05 字号不是三号（约 50%）
6. M01 标题字体不对（约 40%）
7. M04 发文字号括号错误（约 30%）
8. L02 第三层次顿号（约 25%）
